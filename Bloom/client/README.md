# Project Bloom - Client

This is the cross-platform Flutter application for Project Bloom.

## Folder Structure

- `lib/core`: Core application utilities, constants, theme, and routing.
- `lib/domain`: Pure business logic (e.g., Scheduling Engine).
- `lib/data`: API clients, local persistence, repositories.
- `lib/presentation`: UI screens, widgets, and state management.

## Setup

Run `flutter pub get` and `flutter run` to start the app.
