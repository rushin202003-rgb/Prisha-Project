# PRD-007 — Functional Feature Requirements (Part 2)

## F-003 AI Companion
Can explain chapters, answer learning questions, generate study plans, suggest revision, provide multiple teaching modes, encourage progress, and support reflection.

Teaching modes:
- Teacher
- Story
- Visual
- Quiz
- Game
- Surprise Me

## F-004 Homework Manager
Add subject, due date, estimated duration, edit, complete, delete.

## F-005 Notes Manager
Record missed notes, summaries, subject/chapter tags, completion, search. Future OCR and Apple Pencil support.

## F-006 Worksheet Manager
Add worksheets, subject, due date, completion, submission status.

Modules should support appropriate offline entry and later synchronisation.
