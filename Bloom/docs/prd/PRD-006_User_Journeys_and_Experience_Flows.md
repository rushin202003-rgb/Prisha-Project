# PRD-006 — User Journeys & Experience Flows

## Core daily journey
1. Morning dashboard
2. School-time capture where needed
3. After-school check-in
4. AI planning session
5. Study sessions
6. Breaks
7. Hobby/play time
8. Evening reflection
9. Tomorrow preview

## Adaptive journeys
- Feeling sleepy
- Family plans
- Illness
- Unexpected homework
- Visitors
- Exam tomorrow

The AI should offer revised schedules rather than silently changing plans.

## Parent journey
Parents see meaningful progress, upcoming exams, homework status, revision progress, and achievements without automatically receiving private journal content.
